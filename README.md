# ChapterLab

ChapterLab is the ITSD 85 final project for a private study workspace. A student pastes a chapter excerpt, generates a concept guide and five practice questions, checks the source behind each answer, and retries missed questions.

## Project layout

`frontend/` will contain the React client. `backend/` will contain FastAPI, migrations, and API tests. `deploy/` will hold the Caddy and deployment configuration. Repository automation will live under `.github/workflows/` when the first CI workflow is added.

This folder contains planning artifacts. Run instructions, the public URL, and OpenAPI generated by FastAPI will be added as the deployed workflow is verified.
